# Git Deck README artwork

`git-deck-banner.png` is the README banner, generated with the built-in image generation tool. `git-deck-icon.png` is its transparent, symbol-only app icon variant. `Build-GitDeck.ps1` converts it into 16/24/32/48/64/128/256px Windows ICO frames and the embedded PNG used in `web/favicon.svg` (browser and About).

Icon edit prompt (built-in imagegen, using the banner as reference):

> Use the supplied Git Deck banner as the edit reference. Extract/recreate ONLY its emerald stacked-card symbol with the white three-node branching graph, preserving its recognizable design, colors and orientation. Remove all lettering and all background. Produce a clean square app icon PNG with genuine transparent background. Center the symbol, fill 88 percent of square width/height with even safe padding. Crisp simplified edges and bold node/connector weights readable at 32px, restrained shading, no drop shadow outside symbol, no text, no new decorative details.

Generation prompt:

> Use case: logo-brand. Create one polished GitHub README brand banner for an independent Windows Git client named Git Deck. Wide landscape 3:1 composition. Deep midnight green solid background with extremely subtle tonal depth. Centered horizontal logo lockup: on the left an original crisp geometric emerald and mint symbol combining a branching git graph with three circular commit nodes and two elegantly stacked deck/card planes, strong simple silhouette, restrained dimensional depth, no busy decoration; on the right the exact text 'Git Deck' in refined bold modern sans-serif, ivory white, beautifully kerned, readable at small size. Generous balanced breathing room. Professional premium developer-tool identity, clean and calm. No other text, no watermark, no GitHub cat, no GitLab fox, no Sourcetree logo, no copied trademark symbols. Output finished banner artwork only, not a mockup or contact sheet.
